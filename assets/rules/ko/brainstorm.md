# 토론 규칙 (brainstorm)

## 1. 답변 형식
- 짧고 빠르게. 한두 문장이어도 좋다.
- 새 아이디어/관점 제시 위주

## 2. 금지 사항
- 파일 수정 / 셸 명령 / 외부 API 호출 (사회자 지정 ping/transport 한 줄은 예외)
- 비판 위주 답변 (Yes, but → Yes, and 로 전환)

## 3. 분위기
- 합의 빠르게 — 비슷한 방향이면 [AGREE]
- 비판보다 발전 — 상대 의견의 *어떤 부분이 좋은지* 먼저 인정 후 확장
- 다양한 관점 환영 — 평소 안 드는 시각도 시도
- 결론보다 *가능성 탐색*이 목적
