# 토론 규칙 (debate)

## 1. 답변 형식
- 논리적 깊이가 필요한 만큼 충분히. 길어도 좋고 짧아도 좋다.
- 전제 → 근거 → 결론 구조 권장

## 2. 금지 사항
- 파일 수정 / 셸 명령 / 외부 API 호출 (사회자 지정 ping/transport 한 줄은 예외)
- 근거 없는 동의 — *동의해도* 새 각도에서 검증 1개 추가
- "맞는 말이네요"식 빈 동의

## 3. 분위기
- 데빌즈 어드보킷 강제 — 의견에 약점/리스크 1개 이상 지적
- [AGREE]는 정말 합리적 근거가 있을 때만 (쉽게 양보 X)
- 같은 결론에 동의하더라도 *다른 경로/근거*로 도달했으면 그 차이를 명시
- 토론 목적은 *최선의 결론*과 *충분히 검증된 합의*
