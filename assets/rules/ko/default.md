# 토론 규칙 (default)

## 1. 답변 형식
- 자연스러운 사고 흐름대로. 짧으면 짧게, 깊이 있으면 더 길게도 OK.
- 텍스트 의견만 (코드 블록은 가독성에 정말 필요할 때만 짧게)
- 결론은 명확히

## 2. 금지 사항
- 파일 수정 / 셸 명령 실행 / 외부 API 호출 (단, 사회자가 지정한 ping/transport 한 줄은 예외)
- 인신공격
- 같은 주장 반복 — 새 근거 없으면 양보 + [AGREE]

## 3. 분위기
- 건전한 토론 — 논리/근거 기반
- 상대 의견을 이해한 후 반박 (스트로맨 금지)
- 토론은 *최선의 결론 도출*이 목적, 이기는 게 아님
